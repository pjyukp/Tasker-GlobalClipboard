## 项目概述

**全局剪贴板** 是一个运行在 Tasker 上的剪贴板增强工具，通过监听系统剪贴板变化，自动记录所有复制内容，并提供丰富的管理与检索功能。

- **项目名称**：全局剪贴板
- **Tasker 版本**：6.7.6-beta
- **数据目录**：`/sdcard/Tasker/剪贴板/`
- **核心场景**：WebView + JavaScript 实现的高性能列表界面

## 核心功能

### 1. 剪贴板历史记录

- 自动监听并记录剪贴板内容(需开启配置文件剪贴板变更)
- 记录时间戳、使用时间、收藏状态、置顶状态


### 2. 多视图模式

| 模式 | 说明 |
|------|------|
| **全部（all）** | 显示所有剪贴板记录(无限制，预计几万条也不会有什么问题)，按时间倒序 |
| **最近（recent）** | 仅显示最近使用的记录（上限可配置，默认 1000 条） |
| **收藏（fav）** | 仅显示已收藏的记录 |

### 3. 全文搜索

- **批量搜索**：分批处理搜索任务，避免界面卡顿
- **包含/取反搜索**：搜索时可在输入框左边切换搜索方式(默认包含)
- **叠加搜索**：支持多级搜索结果回溯（返回上一级搜索范围），叠加搜索减少搜索范围，对于查找印象中的历史数据非常有效
- **搜索预览**：高亮显示匹配片段，展示上下文。(取反搜索无高亮)
- **搜索懒加载**：搜索结果分批渲染，提升响应速度
- **可暂停/继续**：大数据量搜索支持中途暂停和恢复(滑动到底部时继续搜索)

### 4. 收藏与置顶

- **收藏（Favorite）**：标记重要内容，单独视图查看
- **置顶（Pin）**：将常用内容固定在列表顶部
- 支持长按菜单快速操作

### 5. 多种输入方式

| 方式 | 说明 | 缺点|
|------|------|------|
| **edge** | 通过发送 Xposed Edge Pro 输入文本的intent输入文本 | 输入长文本时过慢，需安装Xposed模块 |
| **shortx** | 通过 ShortX 原生功能输入 | (当前ShortX版本下_v1.10-1-2999eed-feats
1492397)无法输入首尾所有空白字符(换行符/空格)。 需安装xposed模块 |
| **shortid** | 通过 ShortX 的一键指令输入文本，需要配置ShortX的一键指令，并传递run的指令ID为变量。 | 无明显缺点 |
| **adb** | 通过 ADB 命令输入文本（需安装配套 APK）| 配置麻烦，使用时输入法会切换跳动。 |
| **tasker** | 默认使用Tasker的任务调用Tasker原生功能输入文本 | 使用时输入法会跳动 |

输入内容自动分段处理，支持超长文本（>10000 字符）的智能分段。

### 6. 视图锁定

- 锁定视图后，点击条目直接输入而不关闭界面
- 适合需要连续粘贴多条内容的场景
- 锁定状态下禁止切换视图模式，返回会直接退出

### 7. 数据管理

- **自动去重**：相同 MD5 内容自动合并，保留最新时间戳
- **预览缓存**：快速预览机制，提升列表加载速度
- **数据备份**：索引文件双备份机制，防止数据丢失
- **防抖保存**：写入操作防抖合并，减少 IO 次数

### 8. 翻译集成

- 集成翻译任务，支持选中内容翻译
- 可配置翻译任务名称和按钮文本
- 支持列出所有翻译结果

## 数据结构与存储

### 文件结构

```
/sdcard/Tasker/剪贴板/
 ├── 预览剪贴板.csv      # 主索引文件
 ├── 预览剪贴板.csv.bak  # 一级备份
 ├── 预览剪贴板.csv.bak.bak  # 二级备份
 ├── 缓存.csv            # 缓存文件
 └── 剪贴板.txt           # 每条记录的完整内容文件，仅用于搜索功能，若出错会导致搜索不准或搜索失败，了通过 重新构造数据.sh 脚本重新构造总数据
 └── [000~999]           #时间戳前3位的文件夹，用于拆分数据存储文件夹，避免一个文件夹存储文件数量过多
     └── abcdefg123456……   #各个数据的md5索引文件
```

### 索引文件格式（CSV）

每行一条记录，字段以逗号分隔：

| 字段 | 说明 |
|------|------|
| recordTime | 记录时间戳（秒） |
| useTime | 最后使用时间戳（秒） |
| favTime | 收藏时间戳（0 表示未收藏） |
| pinTime | 置顶时间戳（0 表示未置顶） |
| md5 | 内容 MD5 哈希值 ，分片数量|
| previewB64 | Base64 编码的预览文本 |
| new | 新文件标识，仅参与启动时重构预览信息，不保存 |

## 使用指南

### 基本操作

| 操作 | 说明 |
|------|------|
| **点击条目** | 直接将条目数据调用输入方式输入到当前焦点 |
| **长按条目** | 弹出上下文菜单（收藏/置顶/编辑/描述/删除/列出翻译/重构预览），描述功能仅在置顶/收藏项使用，重构预览功能仅在锁定时显示，仅重构普通数据的预览文本 |
| **右侧边缘点击** | 展开/收起，查看完整内容预览 |
| **点击搜索按钮** | 打开搜索输入框 |
| **点击最近按钮** | 切换全部/最近视图 |
| **点击收藏按钮** | 切换全部/收藏视图 |
| **点击左上角锁图标** | 切换锁定/解锁模式 |
| **点击添加按钮** | 手动添加新剪贴板条目 |

### 搜索操作

1. 点击搜索按钮打开搜索输入框(输入框确认按钮长按可取消)
2. 输入关键词后开始搜索
3. 搜索过程中可点击搜索按钮中止
4. 搜索结果/暂停中可继续点击搜索，叠加搜索缩小搜索范围
5. 支持返回上一级搜索结果

## 技术实现

### 架构特点

1. **WebView + JavaScript**：主界面完全由 WebView 渲染，JS 逻辑驱动
2. **懒加载机制**：列表虚拟滚动，仅渲染可见区域，支持万级数据流畅滚动
3. **防抖与节流**：文件写入、搜索处理均采用防抖/节流优化
4. **双索引缓存**：维护 MD5 索引和位置索引，快速定位条目

### 核心 JS 模块

| 模块 | 主要函数 | 说明 |
|------|----------|------|
| **数据管理** | `parseLine`, `lineFromItem`, `dedupItems`, `sortData`, `syncFromMainFile` | 数据解析、序列化、去重、排序、同步 |
| **渲染引擎** | `renderList`, `renderNormalBatch`, `createClipElement`, `checkLazyLoad` | 列表渲染、懒加载、元素创建 |
| **搜索系统** | `startSearch`, `processSearchBatch`, `buildSearchPreview`, `pushSearchHistory` | 搜索执行、预览构建、历史栈 |
| **交互系统** | `handleItemClick`, `showContextMenu`, `toggleFavorite`, `togglePin`, `deleteItem` | 点击、菜单、收藏、置顶、删除 |
| **输入系统** | `inputMethod`, `sendNext`, `sendSub`, `shellNext` | 多方式文本输入 |
| **滚动系统** | `scrollToTarget`, `stepScroll`, `cancelScrollAnimation` | 平滑滚动动画 |
| **缓存系统** | `updateAllCaches`, `loadCaches`, `scheduleSave`, `writeIndexFileSafe` | 缓存管理、安全写入 |

### 性能优化

- **快速预览**：保存最近 N 条的预览数据，启动时直接显示
- **分批同步**：从主文件同步数据时分批处理，避免阻塞 UI
- **搜索分片**：搜索任务分片执行，每片之间让出主线程
- **预览重构**：新条目异步重构预览，不阻塞主流程

### 数据安全

- 索引文件双备份机制（.bak 和 .bak.bak）
- 安全写入：先写临时文件再替换，防止写入中断损坏
- 防抖合并：频繁修改合并为一次写入，减少文件损坏概率


## 导入部署教程
 
### 前置权限（必须全部开启，否则功能失效）
 
 1. Tasker 授予所有文件访问权限、写入安全设置权限、后台活动权限、自启动、电池无限制
 2. 系统设置→应用→Tasker→权限：存储、后台弹窗、剪贴板访问全部允许
 3. 如需ADB输入：额外授予ADB文本输入APP写入安全设置、文件访问权限
 
 步骤1：导入项目
 
  1. 下载  全局剪贴板.prj.xml  保存到手机/sdcard/Tasker/projects/全局剪贴板.prj.xml
  2. 打开Tasker → 底部小房子 → 导入项目
  3. 选中下载好的项目文件名，等待任务/场景/配置自动导入完成
