全局剪贴板 - Tasker完整剪贴管理项目
 
项目简介
 
这是一套基于Tasker Scene 打造的全功能本地剪贴板管理器，全程离线存储，无需联网，自动监听系统剪贴变更，支持多条记录持久保存、置顶、收藏、检索、多方式文本输入，兼容ShortX、Xposed Edge、ADB输入方案，解决原生剪贴仅存一条的痛点。
 
核心特性
 
1. 实时监听剪贴：配置「剪贴板变更」事件，复制任意文本自动入库持久化
2. 本地分层存储：文件按前3位时间戳分目录存放，避免长期使用导致单目录子文件过多问题，超大文本自动分片拆分
3. 完善列表操作：置顶排序、收藏夹、最近使用视图、单条删除、自定义描述
4. 内置搜索引擎：支持全文检索/预览检索，分批加载不卡顿长列表
5. 多端输入适配：Tasker任务、ShortX指令、Xposed Edge、ADB输入法4种输出方案
6. 现代化UI：深色暗色Web界面，手势长按菜单、滑动排序、Toast提示、滚动懒加载
7. 数据自愈机制：内置Shell脚本修复索引文件、缓存文件损坏问题
8. 轻量化缓存：启动优先加载缓存快速渲染，后台同步完整索引不卡顿

导入部署教程（安卓Via浏览器/GitHub下载通用）
 
前置权限（必须全部开启，否则功能失效）
 
1. Task 授予所有文件访问权限、后台活动权限、自启动、电池无限制
2. 系统设置→应用→Tasker→权限：存储、后台弹窗、剪贴板访问全部允许
3. 如需ADB输入：额外授予ADB文本输入APP写入安全设置、文件权限
 
步骤1：导入项目
 
1. GitHub仓库下载  全局剪贴板.prj.xml  保存到手机/sdcard/Tasker/projects/全局剪贴板.prj.xml
2. 打开Tasker → 底部小房子 → 导入项目
3. 选中下载好的项目文件名，等待任务/场景/配置自动导入完成
4. 导入完成后可见任务列表：
- 全局剪贴板（启动场景主任务）
- 剪贴板变更（监听配置）
- 剪贴板记录（写入数据核心）
- 编辑剪贴板数据（新增/编辑/搜索弹窗）
- 附加配置（ADB工具、修复脚本、Short指令）
 
全局剪贴板界面功能详解
 
顶部导航栏
 
- 标题+计数：当前视图总记录数量
- 🔍 搜索：打开搜索弹窗，当前视图搜索文本，支持叠加搜索、取反检索
- ⭐ 收藏夹：切换仅显示收藏条目，可移动、编辑修改、编辑条目描述文本，
- ⌛ 最近使用：按点击时间排序常用剪贴
- ⏎ 返回：收起展开条目/退出搜索/切回全部/关闭窗口
- ✚ 新增：手动输入文本添加剪贴记录
 
列表条目
 
1. 数字角标：排序序号，置顶/收藏自动变色标识
2. 文本预览：默认单行截断，点击条目直接调用输入方式输入文本
3. 右侧边缘点击：展开完整内容+MD5+记录时间
4. 长按条目：弹出操作菜单
- 置顶/取消置顶
- 收藏/取消收藏
- 编辑内容
- 添加自定义描述(仅置顶/收藏)
- 删除本条记录
5. 上下滑动长按条目：调整置顶/收藏内部排序
 
四种文本输入方案（按需切换）
 
打开任务「全局剪贴板」可修改变量  %输入方式  切换：
 
1. tasker（默认）
 
原理：Tasker任务原生操作输入文本
优点：无需额外APP
缺点：弹出输入框会短暂切换输入法
 
2. shortx
 
原理：调用ShortX原生输入文本接口
优点：切换输入法无抖动，流畅
缺点：首尾多个空格、换行存在丢失问题
 
3. shortid
 
原理：调用内置ShortX一键指令
前置：运行「附加配置」导出ShortX指令并导入软件
 
4. edge
 
原理：Xposed Edge Pro Intent输入
优点：后台静默输入，不弹窗
缺点：超长文本分段发送，速度较慢
 
5. adb
 
原理：配套ADB输入APP注入文本
前置：运行「附加配置」导出apk安装，授予系统写入权限
缺点：会临时切换输入法
 
数据维护与修复
 
1. 重建损坏索引
 
当列表空白、预览加载失败：文件损坏
运行任务「附加配置」→执行 重新构造数据.sh 脚本，可选择性重建预览csv、原始剪贴文本库。
 
2. 备份迁移
 
整个  /sdcard/Tasker/剪贴板  文件夹复制即可完整迁移所有剪贴记录，无需导出项目。
 
3. 清理冗余
 
删除列表条目会同步删除对应分片文本文件，无残留垃圾；缓存文件自动生成无需手动清理。
 
配套工具使用
 
ShortX一键指令
 
1. 运行「附加配置」任务，导出  ShortX-输入剪贴板文本.txt 
2. 文件分享选择ShortX导入一键指令
3.  %输入方式  设置为  shortid  即可调用
 
ADB文本输入工具
 
1. 运行「附加配置」自动释放adb.apk到剪贴目录
2. 安装APP，授予：全部文件、写入安全设置
3.  %输入方式  修改为  adb  启用
 
常见问题FAQ
 
Q1 复制文字不自动保存
 
A1：检查「剪贴板变更」配置文件是否启用；Tasker后台被杀，关闭电池优化，开启自启动。
 
Q2 界面空白无任何记录
 
A2：首次运行未生成目录，执行一次「剪贴板记录」；索引损坏运行修复脚本。
 
Q3 图片/文件剪贴无法保存
 
A3：本项目仅纯文本剪贴管理，图片/媒体不在存储范围内。
 
Q4 长文本展开不全/粘贴截断
 
A4：超大文本自动分片存储，切换shortid/adb输入模式，避免原生Task截断。
 
Q5 搜索不到内容
 
A5：检查/剪贴板.txt 文件是否损坏，可用内置脚本重建。
 
Q6 导入项目报错
 
A6：Tasker版本建议6.7.5及以上（项目开发版本），低版本搜索Scene V2不兼容，也可用Scene V1另建一个输入框场景。
